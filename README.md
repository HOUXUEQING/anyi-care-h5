# 安颐照护 · 居家与院内照护 H5

面向 C 端家庭的专业照护服务下单 H5：选择居家照护或院内陪护服务，填写服务对象与照护需求，提交订单并查看服务进度。

纯静态实现，无构建依赖，移动端优先（390px 设计，适配 320px–430px），可在任意静态托管直接部署。首页视觉参考医疗健康类 App：浅色渐变与玻璃质感、轻量进行中服务卡、双场景功能卡、柔和色块线性图标与悬浮底部导航。

## 功能一览

### 1. 首页
- 浅色渐变 + 玻璃质感背景，顶部城市、消息、客服入口
- **轻量进行中服务卡**：首页顶部浅色玻璃渐变，服务状态、时间、时长、地址分开展示，护理员姓名 / 资质 / 持证标识，点击进入订单进度
- 2 张浅色场景卡（并排）：居家照护浅绿、院内照护淡黄，标题与副标题左上对齐
- 8 个照护场景图标面板：柔和底色 + 深色线性图标，长期照护、术后康复、助浴助洁、夜间陪护、母婴护理、陪诊陪检、院内陪护、重症专护
- 品牌横幅“守护家人 安心照护”，咨询入口
- 悬浮式底部四栏导航：首页 / 服务 / 订单 / 我的，订单有进行中服务时显示红点

### 2. 服务浏览
- 12 项服务（居家 6 项、院内 6 项），支持全部 / 居家 / 院内切换
- 综合推荐、好评优先排序
- 关键词搜索：服务名称、副标题、标签、简介全文匹配，含热门搜索词
- 服务详情：蓝色渐变头图、浅蓝底白色卡片、蓝色丝带标题、橙色「立即预约」、编号流程时间轴、信任保障条；含服务包含、适合人群、评分与评价、常见问题

### 3. 填写服务信息
顶部为与订单详情一致的五段进度条（填写信息 / 提交订单 / 护理员接单 / 服务开始 / 服务完成），当前步骤环形高亮，后续步骤为灰色圆点；页头居中标题，下方为服务摘要与 6 个分区表单。

| 分区 | 内容 |
| --- | --- |
| 01 服务对象 | 姓名、性别、年龄、与本人关系、联系电话 |
| 02 服务地点 | 居家：常用地址选择 / 新增地址；院内：医院、科室病区、床号、住院号 |
| 03 服务时间 | 开始日期（不早于今天）、开始时间、服务时长/天数/次数 |
| 04 照护需求 | 自理能力、特殊需求多选（鼻饲、导尿、压疮、康复、失智、吸痰等）、补充说明 |
| 05 联系人 | 联系人、手机号、紧急联系人 |

- 校验失败自动定位到首个错误字段，并给出具体提示
- 地址可现场新增，保存后自动选中

### 4. 下单与确认
- 提交后生成订单号 `AY + 日期 + 4 位流水`，进入提交成功页
- 提交后订单直接进入「待接单」，约 6.5 秒后自动模拟护理员接单，并短信式 Toast 通知

### 5. 订单与进度
- 订单列表：全部 / 待服务 / 服务中 / 已完成，卡片展示服务、时间、地点、合计、快捷操作
- 订单详情：状态头图、五段式进度条（填写信息 → 提交订单 → 接单 → 服务开始 → 完成）、订单进度时间轴、护理员名片与资质、服务打卡记录、服务信息、订单信息
- 状态流转：
  - 待接单 → 取消订单 / 联系客服
  - 待服务 → 联系护理员 / 确认服务开始
  - 服务中 → 联系护理员 / 确认服务完成
  - 已完成 → 再次预约 / 评价服务（星级 + 标签 + 文字）
  - 已取消 → 联系客服 / 重新预约
- 复制订单号、拨打客服电话、在线沟通入口
- 每月/每单的进度都留有事件时间线，刷新或下次打开仍可查看

### 6. 我的
- 会员信息、累计服务、服务中/已完成统计
- 订单状态快捷入口与角标
- 长辈档案、常用地址管理（新增 / 删除）
- 在线客服、帮助中心、关于、服务热线

## 完整演示路径

1. 首页点击「居家照护」→ 选择一个服务 → 查看详情
2. 「立即预约」→ 填写服务信息（已预填长辈档案，可直接调整）
3. 勾选协议 → 提交订单 → 进入订单进度
4. 约 6.5 秒后护理员自动接单，点击「确认服务开始」
5. 查看服务打卡记录，点击「确认服务完成」
6. 评价服务（星级 / 标签 / 文字），在订单列表查看评价
7. 返回首页可见「进行中的服务」；也可体验院内照护下单、取消订单、新增地址

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- Hash 路由：`#/`、`#/services/home`、`#/service/:id`、`#/book/:id`、`#/success/:id`、`#/orders/:tab`、`#/order/:id`、`#/mine`、`#/search`
- 图标全部为内联 SVG symbol，无外部图片与字体依赖
- 安全区适配：`env(safe-area-inset-bottom)`，底部导航与操作栏固定
- 桌面端自动居中为 430px 手机画布，便于分享预览
- 数据持久化：`localStorage`（键名 `anyi-care-v1`），保存订单、地址、用户信息

### 演示数据说明

- 首次打开会预置 1 个「服务中」订单（院内 24 小时陪护）和 1 个「已完成 + 已评价」订单，便于直接查看进度页
- 接单、取消等进度均为前端模拟
- 清空演示数据：浏览器控制台执行 `localStorage.removeItem('anyi-care-v1')` 后刷新；或调用 `window.__ANYI__.reset()`

### 验收

`tools/check.mjs` 使用无头 Edge/Chrome 在 390×844 @2x 下跑通完整链路，覆盖：首页 → 列表 → 详情 → 预约 → 提交 → 接单 → 开始服务 → 完成 → 评价 → 订单列表 → 我的；同时在 390px 与 430px 宽度下检查横向占满、模块左右边距、底部操作栏间距（预约页 28.9px、订单详情 44.2px），并校验无 JS 报错、无横向溢出。

```bash
# 需先启动本地服务，并安装 Edge 或 Chrome
node tools/check.mjs
```

## 上线前建议

1. 将 `app.js` 中的订单、地址、评价逻辑替换为真实后端接口（建议 REST/GraphQL + 鉴权）
2. 补充实名认证、服务协议与隐私政策正式文本、电子合同签署
4. 护理员接单、打卡、签退建议由护理员端小程序完成，C 端只读展示
5. 增加订单消息推送（短信 / 服务号模板消息）与客服会话能力
6. 服务范围、城市覆盖与订单规则应由服务端配置下发

## 设计说明

- 品牌色：专业蓝 `#1B63D5`，浅蓝底 `#E9F1FE`
- 首页采用参考图的“浅色渐变 + 玻璃卡片 + 柔和功能卡 + 色块线性图标”风格：2 张场景卡并排，8 个服务入口 4×2 排列
- 我的页面、订单详情页顶部沿用首页的浅蓝 / 青色渐变，避免大面积深色背景
- 卡片圆角 18–26px，低对比阴影，留白充足，强调“安心、专业、可信赖”
- 操作栏固定在视口底部，内容区预留 `92px + 安全区`；悬浮导航预留 `104px + 安全区`，底部信息不会被遮挡
- 服务封面使用品牌色渐隐底 + 场景线性图标，避免图片加载与版权问题
- 数字使用 DIN 风格字体栈，订单号与时间更清晰
- 图标统一 1.7px 描边，24×24 视窗
